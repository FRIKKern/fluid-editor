# Fluid editor · Tuesday 24 November 2026

1 pull request merged ([#772](https://github.com/FRIKKern/fluid-editor/pull/772)). A check runs our editor through recorded steps and compares it with what Squarespace's real editor, the oracle, was seen to do. It went to the Scrolling block, whose words run along a wave, in the phone view.

## What a person can now do

Run `npm run dev` and open the editor.

### A block below a Scrolling block, on the phone

1. Add a Scrolling block, and a Text block under it in the same section.
2. Open Mobile View, edit the Scrolling block and raise its Wave Intensity to 180. The Scrolling block grows, and the Text below moves down by as much, keeping its height. The section grows with them, from 4 phone rows to 9.
3. Set the wave to 90. Both come back up, and the section shrinks to 6 rows.
4. A second Scrolling block below does the same. Before, the block below stayed where it was, under the Scrolling block.

The desktop view is not touched, and a block hidden in the phone view stays where it is. The oracle was read in two sessions, in opposite orders, and they agreed on all 34 reads. Animation speed, Fade edges, Item Spacing and Text Size in the phone view were read too; ours already matched them.

## Checks that got harder to fool

scrolling-check grew from 265 to 287 rows. On main's app 6 of the 22 new rows are red, the ones with a block below; each row also checks that its press landed ([#772](https://github.com/FRIKKern/fluid-editor/pull/772)).

## Where it is slow or rough

- No guess was written down before the reads, so the rule is fitted, not predicted ([#772](https://github.com/FRIKKern/fluid-editor/pull/772)).
- Inferred, not read: a block with rows between it and the Scrolling block's foot, a block below during a live wave drag, after Text Size or an item edit, and spare rows under the lowest block. Not read at all: a block above or beside, a block below on the desktop, more than two blocks in a section, and Cmd+Z after these steps ([#772](https://github.com/FRIKKern/fluid-editor/pull/772)).
