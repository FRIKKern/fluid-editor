# Fluid editor · Wednesday 25 November 2026

27 pull requests merged, three of them the News for Sunday to Tuesday ([#795](https://github.com/FRIKKern/fluid-editor/pull/795), [#796](https://github.com/FRIKKern/fluid-editor/pull/796), [#798](https://github.com/FRIKKern/fluid-editor/pull/798)). A check runs our editor through recorded steps and compares it with what Squarespace's real editor, the oracle, was seen to do. Every other PR went to the Scrolling block, whose words run along a wave: 14 to how it moves the blocks around it and takes its undo steps, 3 to its Link row, and 7 to scrolling-check, the check that reads it.

## What a person can now do

Run `npm run dev` and open the editor. An area such as 3/2/5/10 reads top row, left column, bottom row and right column of the section's grid.

### The blocks around a Scrolling block

1. Add a Scrolling block (1/2/3/26 on the desktop) and a Text block under it (3/2/5/10).
2. On the desktop, set Wave Intensity to 180. The Text block moves down with the foot, to 7/2/9/10, and back to 4/2/6/10 at 90. Before, nothing moved on the desktop ([#776](https://github.com/FRIKKern/fluid-editor/pull/776)).
3. A block follows only when it shares a column with the Scrolling block and starts on or below its top row. A block beside it in other columns stays, in either view ([#775](https://github.com/FRIKKern/fluid-editor/pull/775)).
4. Set 150, then 0. A block on the Scrolling block's top row lands on the new foot, at 2/2/4/10, not on row 0 ([#786](https://github.com/FRIKKern/fluid-editor/pull/786)). A one-step fall on the desktop, 180 to 150, leaves a block on the Scrolling block's rows where it is ([#797](https://github.com/FRIKKern/fluid-editor/pull/797)).
5. Put a second Scrolling block on the first's area, 1/2/3/26, and set 150. Both grow to 1/2/6/26: a block with the same top row and columns is stretched, not moved ([#799](https://github.com/FRIKKern/fluid-editor/pull/799)).

Text Style now keeps the rows after a fall, as the other presses did ([#777](https://github.com/FRIKKern/fluid-editor/pull/777)), and after a fall in the phone view the phone still follows a move made on the desktop ([#779](https://github.com/FRIKKern/fluid-editor/pull/779)).

### Wave Intensity in each view

Open Mobile View and set Wave Intensity. It is the phone's own: the desktop line stays flat, its panel shows 0, the phone-only button turns on and the label is dotted. Before, one value drew the wave in both views ([#781](https://github.com/FRIKKern/fluid-editor/pull/781)).

### Undo after a Wave drag or arrow keys

1. Drag Wave Intensity, pausing a second or more on a value. Each pause is one undo step, and the let go takes the last, even back where the drag began ([#782](https://github.com/FRIKKern/fluid-editor/pull/782)). Let go on the value a pause left, and that step is still taken ([#794](https://github.com/FRIKKern/fluid-editor/pull/794)).
2. Press ArrowRight on the range. The value moves by 30 and the range keeps the focus; before, the second key moved the selected block. Keys about 230 ms apart are one step together ([#790](https://github.com/FRIKKern/fluid-editor/pull/790)).
3. A touch drag the browser cancels lets go as a pointer drag does ([#791](https://github.com/FRIKKern/fluid-editor/pull/791)). On the desktop, a drag leaves a Text block below where the rise took it as the foot falls ([#784](https://github.com/FRIKKern/fluid-editor/pull/784)), and in the phone view a drag's step on the way back holds the rows it had on the way out ([#787](https://github.com/FRIKKern/fluid-editor/pull/787)).

### The Link row

While Attach link's editor is open, the Link row still reads Attach link, a page picked or not ([#773](https://github.com/FRIKKern/fluid-editor/pull/773)). A press on it after a pick closes the editor with the focus on the row's Edit ([#780](https://github.com/FRIKKern/fluid-editor/pull/780)); after a typed link, on the row's link ([#783](https://github.com/FRIKKern/fluid-editor/pull/783)).

## Checks that got harder to fool

- scrolling-check grew from 287 to 820 rows. Each behaviour change came with rows red on main's app, from 1 ([#783](https://github.com/FRIKKern/fluid-editor/pull/783)) to 44 ([#799](https://github.com/FRIKKern/fluid-editor/pull/799)).
- Its hosted step limit went from 20 to 45 minutes: the step grew from 11.4 to over 18 minutes in 14 hours, and a 647-row run timed out ([#793](https://github.com/FRIKKern/fluid-editor/pull/793)).
- It now stops at once in a Chrome whose scrollbars take width, which moved a row by 7.5 px ([#789](https://github.com/FRIKKern/fluid-editor/pull/789)). Four other checks start from a clean editor after it ([#774](https://github.com/FRIKKern/fluid-editor/pull/774)).
- Rows that could pass on a broken app now catch it: an undo that left the heading a paragraph ([#778](https://github.com/FRIKKern/fluid-editor/pull/778)), a guard the drag change had stopped reaching ([#785](https://github.com/FRIKKern/fluid-editor/pull/785)), and a layout turn back to Text ([#788](https://github.com/FRIKKern/fluid-editor/pull/788)), whose rows no longer lean on a block an earlier part left ([#792](https://github.com/FRIKKern/fluid-editor/pull/792)).

## Where it is slow or rough

- Where between 0.25 and 1.2 s keys stop joining one step, and between 870 and 1,100 ms for a drag, was not read: ours uses 1 s. Page Up, Page Down, Home and End were not read; Item Spacing and Text Size take the same rule unread ([#782](https://github.com/FRIKKern/fluid-editor/pull/782), [#790](https://github.com/FRIKKern/fluid-editor/pull/790)).
- In the phone view, a one-step fall still moves a block that starts above the old foot; that was not read. After a phone fall, our first Cmd+Z gives other rows than the oracle's ([#797](https://github.com/FRIKKern/fluid-editor/pull/797)).
- The phone button's Reset and Push to desktop after a phone Wave value were not read ([#781](https://github.com/FRIKKern/fluid-editor/pull/781)). No real touch screen was used ([#791](https://github.com/FRIKKern/fluid-editor/pull/791)).
- A stretched block shorter than the Scrolling block, or two of them, was not read ([#799](https://github.com/FRIKKern/fluid-editor/pull/799)).
- At about 1.9 s a row on the hosted runner, 45 minutes holds about 1,400 rows ([#793](https://github.com/FRIKKern/fluid-editor/pull/793)).
